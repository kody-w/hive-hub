Hive folder convention (HIVE-MD)

experimental birch-juniper-harbor-oxbow-larch-elm-jasper

A Hive is a git repository of markdown files: HIVE.md, members/<name>/keys/<device>.md, requests/, shared/ and former/. Every change is an SSH-signed commit, judged by the Hive as it stood at its parent. The checker and the agent are one file from the same commit as the spec. The agent's join takes the address and the root commit (as id), checks every commit from that root, pins the root and the Hive id, and shows the founder key fingerprint, which must match the Hive card. Experimental: it is in the frontier track's canary ring and has not yet been used by a real team for a real week.
