The Private Hive profile in force: one owner, signed RAPP/1 frames, and channels such as a private Git repository that carry one authority. The checker comes from the same commit as the spec: an independent client runs client init with the owner's anchor, then client pull, then client verify. No Brainstem agent is pinned here, because nobody joins a rapp-hive/1 Hive by request: the owner's signed declaration names its members, and that roster cannot change yet (gap G1).
