Your first shift

Deliver a glow cell to every ○ beacon. You carry only one. Return to the D depot to reload automatically.

The = bridge opens for beats 1–2, then closes for beats 3–4. Enter only while open. You can always leave a bridge beneath your feet. Watch the next-action phase in the status.

Arrows / WASD move. Space waits one beat. U / Backspace undo. R restarts. These keys work while the board is focused.

  • A blocked move does not spend a beat.
  • A filled ★ beacon needs no more cells.
  • ◆ is you. No time limit. Undo is welcome.
  • Win each board independently; switch boards with the selector.
