# Conditional first-shift release gate

SYNTHETIC production exercise. This is a checklist, not completed QA evidence.

1. Preserve an untouched reference copy; record the exact candidate file list.
2. Run the engine and feedback tests. Record command, result, and date.
3. Open the candidate from disk. Focus the board. Exercise every documented key,
   wait on a closed bridge, win, undo a win, restart, and change levels.
4. Disable networking. Confirm that gameplay still works and no remote asset or
   transport is requested. Static source inspection alone is not this test.
5. Verify that loading is silent, opt-in sound is short, and unsupported audio
   leaves text and gameplay intact.
6. Review at 320px width and with keyboard only. Use a screen reader if available;
   otherwise record that check as unrun, not passed.
7. Verify that no feedback collection, personal data, analytics, persistence,
   remote code, copyrighted borrowed assets, or publication was added.
8. Compare the implementation to the frozen scope and every acceptance CSV row.
   A failing or unrun material check produces rework or a documented hold.
9. Prepare a prospective research plan. Never manufacture completion percentages
   from the authored sample or describe it as observed market validation.
10. Present a conditional candidate recommendation to the owner. Publishing,
    recruiting participants, spending, or crossing an organization boundary
    requires a separate approval; this seed performs none of those actions.
