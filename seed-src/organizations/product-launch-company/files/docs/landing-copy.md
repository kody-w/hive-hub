## Headline

Make room for the decisions that matter.

## Short description

Agenda Pocket helps you fit a meeting agenda into a fixed timebox. Mark the
topics that must happen, reserve a wrap, and see which optional topics fit.
Try the local demo without an account or a server.

## Three feature statements

- **Required stays required.** If essential topics do not fit, the planner
  says so instead of quietly dropping them.
- **Tradeoffs stay visible.** See scheduled topics, unscheduled topics, slack,
  and the reserved wrap interval.
- **Your draft stays local to the app.** No application network calls or
  automatic saving. Import a local JSON file and export only when you choose.

## Call to action

Open the offline demo. Start with the clearly labeled synthetic sample.

## Honest limits

Agenda Pocket does not connect to calendars, rank importance, shorten
conversations, guarantee a better meeting, or measure time savings. Optional
topics are considered in the order you enter them. Save an explicit export
before closing if you want to keep the result.
