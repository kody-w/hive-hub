# Juniper Queue investigation — public-source bureau seed

**Every company, notice, benchmark, source label, and business circumstance in
this package is original SYNTHETIC material.** These are public-*style* records,
not fabricated citations to real publications. There are no private people,
real intelligence targets, secrets, or network collection.

## The specific question

As of 17 September 2026, does the included corpus support a fictional
unattended, 72-hour-disconnected kiosk pilot on 15 October? A broad offline
promise conflicts with a 24-hour credential condition. A short-run
acknowledgment metric does not settle recovered-event durability.

From `files/`, run Python 3 with no installs or server:

```text
python3 -I -B tools/evidence.py index
python3 -I -B tools/evidence.py timeline
python3 -I -B tools/evidence.py search "restart"
python3 -I -B tools/evidence.py audit
python3 -I -B tests/test_evidence.py
```

All commands read a fixed local file allowlist and print JSON to stdout. No
source code, commands, remote URLs, adapters, or protocol material are executed.
The index records each source file's SHA-256, record ID, date, exact row, and
original fields. Citations use `sources/<file>.csv#row=N`; the header is row 1.
All source records occupy one physical line, enforced by the utility.

## Reproducible starting evidence

There are eighteen source records in five CSV files, nine coded claims, three
conflict/ambiguity pairs, and six prospective inquiry rows.

- `sources/announcements.csv#row=2`: full-offline launch promise.
- `sources/release-notes.csv#row=3`: no restart after 24 hours offline in preview.
- `sources/support-notices.csv#row=2`: reconnect-to-refresh workaround.
- `sources/benchmark-runs.csv#row=2`: 987/1000 acknowledgments, two hours, no restart.
- `sources/benchmark-runs.csv#row=3` and `#row=4`: 0/400 each after 36 hours;
  application start blocked. These are attempted actions, not lost acknowledged data.
- `sources/benchmark-runs.csv#row=5`: 398/400 acknowledgments and 390 recovered
  IDs after a six-hour restart. The eight-ID difference needs reconciliation.
- `sources/support-notices.csv#row=4`: no documented 72-hour cold-start pass.

Do not pool unlike runs. Blank recovered counts are **unmeasured**, not zero.
Two origin labels are not proof of independent corroboration: lab-style work
used a vendor-supplied device/build. Claim confidence describes the authored
record's interpretability, not a calibrated real-world probability.

## Work and limits

The five teams progress from corpus freeze through index, chronology, competing
hypotheses, verification, conflict review, prospective collection, and briefing.
Files are starter evidence and methods, not completed intelligence work.
Current evidence does not establish launch readiness or prove a schedule slip.
There is no live search connector or real source verification. Contact,
procurement, deployment, data collection, and cross-organization exchange
remain separately owner-approved; this seed creates none of that authority.
