# Community starter

**Fictional contributor workflow; no people, issues, or memberships exist.**

## Example issue description

Title: “Repeated identical event changes the reference count.”

Using the public synthetic duplicate fixture, I expect 3 unique events.
The original reducer returns 4. The repeated `event-a-open` payload is
identical. The clean fixture is unaffected. This is reproducible offline
with the authored CLI; no real logs or host-modifying steps are necessary.

This is an example issue body, not an issue that was opened.

## Minimum intake fields

Project/candidate version, short symptom, exact authored command, minimal
synthetic fixture, expected summary, actual summary, and whether the issue
also appears on the clean case. Environment/version is optional unless
needed for reproduction. A contributor may omit personal identity.

Ask for respectful behavior and precise evidence. Do not request tokens,
credentials, private repository URLs, customer logs, personal data, or a
production reproduction. Do not accept “tests green” without specifying
whether the run was characterization or strict acceptance.

After an actual authorized candidate exists, an owner may decide to share a
draft announcement. Its claims must link to observed fixes and actual
publication evidence. This seed does not create a contributor program,
outreach list, support promise, or community activity.
